# JavaScript Mini Projects

A collection of beginner-friendly HTML, CSS, and vanilla JavaScript projects to practice and showcase frontend development skills.

## 🚀 Projects Included

Here is a list of the projects included in this repository:

1. **Dark-light toggle theme**: A theme switcher (Dark/Light mode) that respects OS default preferences and saves user choices using `localStorage`.
2. **Guess random number**: A fun "Guess the Number" interactive game.
3. **TODO**: A classic To-Do list application to manage daily tasks.
4. **Card and profile**: A clean and responsive UI component for a user profile card.
5. **Download UI**: A modern user interface component simulating a file download progress.
6. **Form and validation**: A complete web form with robust client-side JavaScript validation.
7. **User finder**: An application to search and display user profiles.

## 🛠️ Technologies Used

- **HTML5**: For crafting the structure and semantics of the applications.
- **CSS3**: For responsive and modern styling.
- **Vanilla JavaScript (ES6+)**: For adding interactivity and logic without relying on external libraries.

## 📂 Getting Started

To view any of these projects locally:

1. Clone this repository to your local machine:
   ```bash
   git clone <your-repository-url>
   ```
2. Open the folder of the specific project you want to view.
3. Keep it simple! Just double-click the `index.html` file to open it in your preferred web browser. 

No build tools, compilation, or package managers (`npm`/`yarn`) are required to run these projects.
