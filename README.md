# 🚀 JavaScript Mini Projects Collection

A curated collection of beginner-to-intermediate **HTML, CSS, and Vanilla JavaScript** projects designed to strengthen frontend development skills through hands-on practice.

These projects cover essential JavaScript concepts including DOM manipulation, event handling, local storage, drag-and-drop functionality, form validation, theme management, and interactive UI development.

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/your-username/javascript-mini-projects.git
```

Move into the project directory:

```bash
cd javascript-mini-projects
```

---

## Run Any Project

Simply open the desired project folder and launch the `index.html` file in your browser.

```text
Project Folder
│
├── index.html
├── style.css
└── script.js
```

No additional setup is required.

✅ No Node.js

✅ No npm/yarn

✅ No build tools

✅ No frameworks

Just open and run.
